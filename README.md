\# DocPilot RAG



基于 Python 和 Embedding 模型实现的手写 RAG 学习项目。



\## Project Goal



学习并实现企业级知识库问答系统的核心流程。



最终目标：



\- 多文件文档解析

\- 文本切分

\- Embedding向量化

\- 向量数据库检索

\- LLM生成回答

\- LangChain工程化

\- 企业知识库问答系统
